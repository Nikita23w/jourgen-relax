# Журжень Relax

Шуточный одностраничный SPA для взрослых партнёров. React + TypeScript + Vite. Все фотографии и шрифты локальные, внешних запросов при просмотре нет.

## Запуск

```sh
npm ci
npm run dev -- --port 5173
```

## Проверка

```sh
npm run build
npx playwright install chromium
npm run preview -- --port 4173
npm test
```

Проверка браузера использует http://127.0.0.1:4173. Другой адрес: `SITE_URL`.

## Настройки

Телефон и контент — `src/data.ts`. `PHONE` пока содержит согласованную заглушку `+7 XXX XXX-XX-XX`; для реального звонка замените её настоящим номером. Выбор программы отображается в блоке записи, заявка на сервер не отправляется: запись по телефону.

Три исходные фотографии используются без изменения: `hero.jpg`, `dominant.jpg`, `photo_3_2026-09-15_20-01-24.jpg`. Остальные предоставленные фотографии сохранены в проекте.

## Публикация

Push в `main` запускает `.github/workflows/deploy.yml`. В Settings → Pages должен быть выбран GitHub Actions. Vite использует относительный `base`, поэтому файлы загружаются и из подпапки репозитория.
